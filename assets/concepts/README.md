# PETOPIA concepts

**Work only from `current/`.** Everything in `archive/` is an older or superseded version kept for history; do not use it as a reference.

## current/
- `ui-kit/ui-kit-a49.png`, `ui-kit/screens-a49.png` — approved UI kit (A49). **All UI styling** (panels, buttons, icons, tiles, map markers, tags, meters) follows this, on every screen. The boy/fox drawn in it are not our characters and are not used.
- `screens/` — latest concept per screen: V01 characters (identity of the child and Foxy), V02 adventure (world quality and depth benchmark, not a layout to copy), V04 main menu, V05 adoption, V06 pet details, V07 world map, V08 pause/settings, V09 results. Use them for **content and composition**; where their buttons/frames differ from the A49 kit, the kit wins.
- `home/` — selected A44 home + Care drawer layout (portrait and landscape). The real room and our 2D characters are always used here.

## archive/
Superseded screen versions (V02 v2–v3, V03 home v2–v5, V07 v1, V08 v1), the A47 shared-components sheet (replaced by the A49 kit), early phase-1 direction, the A43 home layout options and rejected explorations.

Runtime production pieces made from the kit live in `assets/ui/kit-v1/` (built by `tools/build_ui_kit.py`).
