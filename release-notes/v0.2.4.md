# PETOPIA 0.2.4 · Lighter on phones, fits the screen

Phones reported a crash while loading (Chrome and Safari), and the game did not fit the visible screen after turning a phone to portrait.

- The loading page now sizes the game to the area actually visible on the phone, re-checks it after rotation, and keeps the page from scrolling, so the bottom of the game is no longer cut off.
- Loading uses less memory at its peak: the engine is prepared before the game file downloads, and the downloaded pieces go straight into one copy of the file.
- If the phone closes the tab during loading, the next visit says which step it stopped at ("Last time, loading stopped while: …").
- Images: the menu icons, coin, home control icons and adventure backdrop now use copies sized to their largest real on-screen size. Images from a screen you have left are released. Measured image memory: menu 100 → 62 MB, home 176 → 126 MB, fetch 168 → 86 MB, back to menu after playing 192 → 76 MB. Before/after captures at 4K desktop, phone and tablet sizes show no visible change.
- A direction held while an adventure opens is no longer dropped.

No changes to gameplay rules, art direction or the save format.

Validation: 467 checks across 13 suites. Local emulated-iPhone browser: loads, fits portrait/landscape/portrait, taps land correctly, crash-step memory shown on next visit. Physical phones still need to confirm the crash is gone.
