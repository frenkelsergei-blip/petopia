# PETOPIA 0.1.0 — First mobile web preview

Play the current PETOPIA build in a browser. This is a playable development preview; final art, audio, the complete care interface and physical-device acceptance remain in progress.

- Native responsive menu and Foxy adoption with saved name and settings.
- My Pet care, four age-based sizes and a separate sleeping Foxy in its bed.
- The Lost Picnic, Windmill Walk, companion cooperation, free crate placement and durable rewards.
- Round movement joystick with captured drags, neutral center and simultaneous action fingers. Shared wood/cream action controls and saved control sizing/spacing.
- Browser-compatible ordered save writer and local browser progress. Existing desktop saves are separate.
- Versioned source tag, browser release metadata, SHA-256 checked asset parts and downloadable web package.

Open the play URL on your phone in Safari or Chrome. The first load downloads the game; progress is stored in that browser on that device.

Physical iOS/Android device verification and final visual approval remain open. This release does not mark the Phase1 art/content gate complete.
