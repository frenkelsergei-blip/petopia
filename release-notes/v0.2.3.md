# PETOPIA 0.2.3 · Clearer browser startup

The loading screen now names each startup step (checking other tabs, checking the version, downloading, checking the download, opening your saved game). If any step makes no progress for 45 seconds, it says which step stalled and shows Try again instead of waiting silently. Pages opened without a secure address explain that instead of failing.

Plain Godot web exports (editor Run in Browser) start the stock game pack instead of stopping at 0% with a 404. Opening `index.html` directly from disk explains how to serve it locally.

No gameplay, art, save writer, transaction or save-schema changes. The single-tab save guard from 0.2.2 is unchanged.

Validation: 461 existing checks across 13 suites. Local Chromium 390×844: packaged and plain exports reach the menu, a deliberately stalled pack part shows the named stall and Try again, second tab blocks and retries after owner close. Hosted bytes and Safari/phones are checked after publishing.
